# Choix des Technologies — MediLink
| Composant | Technologie | Justification |
|---|---|---|
| Frontend | React | Écosystème riche, rapide. |
| Backend | NestJS (Node.js) | Structuré, TypeScript. |
| Base de données | PostgreSQL | Relationnel, robuste pour les RDV. |
| CI/CD | GitHub Actions | Intégré à GitHub, gratuit. |
| Conteneurisation | Docker | Standard de l'industrie. |
| Sécurité | Trivy | Scan de vulnérabilités. |
| Registre | GHCR | Intégré à GitHub. |
| Orchestration | Kubernetes | Standard DevOps. |
| GitOps | ArgoCD | Synchronisation Git → Cluster. |
| Monitoring | Prometheus + Grafana | Standard métriques. |
